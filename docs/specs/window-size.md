# ウィンドウサイズ

設定「ウィンドウのサイズ」で 2 つの挙動を選べます。

- **自由に変更** — 画像の縦横比に関係なく、ウィンドウの端をドラッグして自由に大きさを変えられます。画像を切り替えてもウィンドウの大きさは変わらず、画像はその中に収めて表示します（画像がウィンドウより小さい場合も、縦横比を保ったままウィンドウいっぱいまで拡大します。縦横比が合わない分の余白は背景色のままです）
- **メディアに合わせる** — 余白が出ないよう、ウィンドウの形を表示中の画像・動画の縦横比に合わせます（音楽は「余白＋アートワーク＋曲名の帯」の形。[audio.md](audio.md)）。以下は画像で説明します。前後の画像へ移動するたびに合わせ直し、ウィンドウの端や角をドラッグして大きさを変えるときも、引っ張った辺に合わせて縦横比を保ったまま変わります（縦横比から外れた形にはできません。角を引っ張ったときは、横・縦に合わせた大きさのうち大きい方に合わせます）。ウィンドウの広さ（面積）は引き継ぐので、縦長と横長の画像を行き来しても大きさの印象は変わりません。大きさを画面に収める調整は、アプリを立ち上げて最初に開くときと、ファイルの種類が変わってその種類の大きさへ戻したあと最初に合わせるときだけ行います（画面＝タスクバーなどを除いた作業領域の 95% まで）。それ以外は上限を設けないので、好きなだけ大きくできます（縦長の画像に合わせた結果、画面の下にはみ出すことはあります）

どちらの設定でも、ウィンドウの端や角をドラッグしている間は画像・動画・アートワークの大きさを据え置き（ウィンドウの形だけが変わります）、マウスのボタンを離してウィンドウの大きさが決まったところで合わせ直します。ドラッグの途中で手を止めても、ボタンを押したままなら合わせ直しません。

どちらの設定でも、ウィンドウの大きさと位置は画像・動画・音楽・画像の本モード（[book.md](book.md)）で別々に覚え、それぞれ最後に使ったときと同じ大きさ・同じ位置で開きます（詳しくは下の「ファイルの種類ごとのウィンドウ」）。画面からはみ出す場合は中へ寄せます。前回使っていたディスプレイが外れているなど、保存した位置がどの画面にも載らない場合は位置を戻しません。拡大率（倍率）の違うディスプレイを並べている場合も、閉じたときのディスプレイの同じ場所に、同じ見た目の大きさで開きます。「メディアに合わせる」のときは、開いたあと最初の画像の縦横比に合わせて形だけ整えます（広さと左上の位置はそのままです）。

ウィンドウの大きさと位置は、設定とは別の `window.json` に保存します（`settings.json` と同じ `sview` フォルダに置きますが、設定の「既定に戻す」では消えません）。最小化中・最大化中・全画面表示中に閉じた場合は、その状態ではなく元のサイズと位置を覚えます。

「メディアに合わせる」でも、最大化中と全画面表示中はウィンドウの大きさを変えません（変えるとその状態が解けてしまうため）。元のサイズに戻すと、また画像ごとに合わせるようになります。

## ファイルの種類ごとのウィンドウ

ウィンドウの大きさ・位置・広さ（「メディアに合わせる」で縦横比を合わせるときの基準）は、画像・動画・音楽・画像の本モードの 4 種類で別々に覚えます（設定での切り替えはなく、常に種類ごとです）。ある種類で変えた大きさや位置が、ほかの種類に移ることはありません。

- 表示するファイルの種類が変わったとき（別の種類のファイル・フォルダを開いたとき、本モードと 1 ページ表示を切り替えたとき）、それまでの種類の大きさと位置を覚え、新しい種類で最後に使っていた大きさと位置へ戻します
- その種類をまだ表示したことがなければ、前の種類の大きさや形は引き継がず、既定の大きさ（960 × 640）で、それまでのウィンドウの中心に開きます。ただし種類ごとの記録がまだ 1 つも無いとき（種類ごとに覚える前の `window.json` を使っているとき）は、最初に表示した種類だけ前回閉じたときの姿を引き継ぎます
- 関連付けやコマンドラインからファイルを指定して起動したときは、表示する前にファイルの種類を調べ、最初からその種類の大きさと位置でウィンドウを出します（前回閉じたときの別の種類の姿が一瞬見えることはありません）。ファイルを指定せずに起動したときは前回閉じたときの姿で開き、ファイルを開いたところでその種類の大きさと位置へ移ります
- macOS で Finder から開いて新しいウィンドウが増えるときも、開くファイルの種類で最後に使っていた大きさと位置で開きます（ほかのウィンドウとぴったり重なる場合は少し右下へずらします）
- 「メディアに合わせる」では、戻した大きさ（広さ）と左上を基準に、表示するファイルの縦横比へ合わせます。種類を切り替えて最初に合わせるときは、起動直後と同じく画面（作業領域）の 95% に収めます
- 戻す位置は、どの画面にも載らなければ戻さず、はみ出す分は作業領域の中へ寄せます（起動時の復元と同じ）。拡大率の違うディスプレイをまたいでも、その種類を最後に表示したディスプレイの同じ場所へ戻します
- 最大化中・全画面表示中・最小化中に種類が変わったときは、その状態のままにします（大きさを変えると状態が解けてしまうため）。元のサイズに戻したところで、それまでの種類の大きさと位置を覚え、表示中の種類の大きさと位置へ置き直します。それまでの間は縦横比を固定しません
- 閉じたときは、そのとき表示していた種類の分としても覚えます
- 覚えた内容は `window.json` の `kinds`（`image` / `video` / `audio` / `book`）に入ります。最上位の大きさ・位置は最後に閉じたときの姿で、`kind` はそれがどの種類のものかを表します

なお、縦横比の維持を OS に任せる仕組みが Tauri には無いため、ドラッグ中は「大きさが変わった」という通知が届くたびにアプリ側で縦横比へ引き戻しています。環境によっては、ドラッグ中にわずかに追従が遅れて見えることがあります。
