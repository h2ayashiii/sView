# ウィンドウサイズ

設定「ウィンドウのサイズ」で 2 つの挙動を選べます。

- **自由に変更** — 画像の縦横比に関係なく、ウィンドウの端をドラッグして自由に大きさを変えられます。画像を切り替えてもウィンドウの大きさは変わらず、画像はその中に収めて表示します（画像がウィンドウより小さい場合も、縦横比を保ったままウィンドウいっぱいまで拡大します。縦横比が合わない分の余白は背景色のままです）
- **メディアに合わせる** — 余白が出ないよう、ウィンドウの形を表示中の画像・動画の縦横比に合わせます（音楽は「余白＋アートワーク＋曲名の帯」の形。[audio.md](audio.md)）。以下は画像で説明します。前後の画像へ移動するたびに合わせ直し、ウィンドウの端や角をドラッグして大きさを変えるときも、引っ張った辺に合わせて縦横比を保ったまま変わります（縦横比から外れた形にはできません）。ドラッグしている間は画像の大きさを据え置き（ウィンドウの形だけが変わります）、手を離してウィンドウの大きさが決まったところで画像を合わせ直します。ウィンドウの広さ（面積）は引き継ぐので、縦長と横長の画像を行き来しても大きさの印象は変わりません。大きさを画面に収める調整は、アプリを立ち上げて最初に開くときだけ行います（画面＝タスクバーなどを除いた作業領域の 95% まで）。そのあとはアプリを終了するまで上限を設けないので、好きなだけ大きくできます（縦長の画像に合わせた結果、画面の下にはみ出すことはあります）

どちらの設定でも、ウィンドウは前回閉じたときと同じ大きさ・同じ位置で開きます（画面からはみ出す場合は中へ寄せます。前回使っていたディスプレイが外れているなど、保存した位置がどの画面にも載らない場合は既定どおり中央に開きます）。「メディアに合わせる」のときは、開いたあと最初の画像の縦横比に合わせて形だけ整えます（広さと左上の位置はそのままです）。

ウィンドウの大きさと位置は、設定とは別の `window.json` に保存します（`settings.json` と同じ `sview` フォルダに置きますが、設定の「既定に戻す」では消えません）。最小化中・最大化中・全画面表示中に閉じた場合は、その状態ではなく元のサイズと位置を覚えます。

「メディアに合わせる」でも、最大化中と全画面表示中はウィンドウの大きさを変えません（変えるとその状態が解けてしまうため）。元のサイズに戻すと、また画像ごとに合わせるようになります。

## ファイルの種類ごとにウィンドウを保持する

設定「ファイルの種類ごとにウィンドウを保持する」（既定はオフ）をオンにすると、ウィンドウの大きさと位置を画像・動画・音楽で別々に覚えます。

- 表示するファイルの種類が変わったとき（別の種類のファイル・フォルダを開いたとき）、それまでの種類の大きさと位置を覚え、新しい種類で前に使っていた大きさと位置へ戻します。その種類をまだ表示したことがなければ、ウィンドウはそのままです
- 閉じたときは、そのとき表示していた種類の分としても覚えます。次に起動したときは前回閉じたときの姿で開き、最初に表示したファイルの種類の分を覚えていれば、その大きさと位置へ置き直します
- 「メディアに合わせる」では、戻した大きさ（広さ）と左上を基準に、表示するファイルの縦横比へ合わせます
- 戻す位置は、どの画面にも載らなければ戻さず、はみ出す分は作業領域の中へ寄せます（起動時の復元と同じ）
- 最大化中・全画面表示中・最小化中は、覚えも戻しもしません
- 覚えた内容は `window.json` の `kinds` に入ります。オフにしても消えず、次にオンにしたときにまた使います

なお、縦横比の維持を OS に任せる仕組みが Tauri には無いため、ドラッグ中は「大きさが変わった」という通知が届くたびにアプリ側で縦横比へ引き戻しています。環境によっては、ドラッグ中にわずかに追従が遅れて見えることがあります。
