# 動画

フォルダの中の動画（mp4 / m4v / webm / mov）は、画像と一緒に自然順で並びます。動画を表示している間は `←` `→` が早送り・巻き戻しになるので、前後のファイルへは `Shift` + `←` `→`・`PageUp` `PageDown`・左右の `❮` `❯` ボタンで移ります。

> [!NOTE]
> sView は PC / OS に内蔵の WebView（Windows: WebView2 / macOS: WKWebView）で再生するだけの簡素な作りで、コーデックを同梱していません。
> そのため、**再生できるのはその PC / OS 自体が再生できる形式に限られます**。同じファイルでも、PC のハードウェアや OS のバージョンによって再生できたりできなかったりします（再生できないファイルはエラーを表示します）。

- 形式ごとの目安は次のとおりです

  | 形式 | Windows | macOS |
  | --- | --- | --- |
  | MP4 / M4V（H.264 + AAC） | 可 | 可 |
  | MP4（HEVC） | 対応ハードウェアと OS の HEVC 拡張機能があれば可 | 可 |
  | MOV | 中身によって可（保証なし） | 可 |
  | WebM（VP8 / VP9） | 可 | macOS のバージョンによる |
  | AV1（MP4 / WebM） | 可 | AV1 のハードウェアデコーダを持つ Mac（M3 以降）と macOS 14 以降でのみ可 |

- MKV・AVI などは対象外で、開けません（macOS の WebView はそもそも MKV に対応していません）

- マウスを動かすと、下部中央に再生操作のカードが出ます。上段がシークバー、下段は左に再生時間（現在 / 全体）、中央に 5 秒戻る・再生 / 一時停止・5 秒進む、右に消音と音量です。シークバーにカーソルを乗せるとその位置の時刻、音量つまみに乗せると今の音量が出ます。ほかの表示と同じく、マウスを止めて 3 秒たつか、ウィンドウの外へ出るか、ほかのウィンドウに切り替えると隠れます
- 動画の上を押してすぐ離すと再生 / 一時停止、押したままマウスを動かすとウィンドウを移動します
- 動画は常にウィンドウに合わせて表示し、拡大縮小はしません。設定「画像に合わせる」では動画の縦横比にウィンドウを合わせます
- 設定の「動画」で、開いたらすぐ再生するか・繰り返し再生するか・消音・音量を変えられます（再生バーで変えた消音と音量もここに保存されます）
- 圧縮フォルダ（zip / cbz）の中の動画は一覧に出しません。OS の関連付けもしません（ドラッグ＆ドロップか `O` キーで開いてください）

## 動画表示中のキー操作

動画を表示している間だけ、次のキーが動画の操作になります（それ以外のキーは上の表のままです）。

| キー | 動作 |
| --- | --- |
| `Space` / `K` / 動画をクリック | 再生 / 一時停止 |
| `←` / `→`、`J` / `L` | 5 秒戻る / 進む |
| `↑` / `↓` | 音量を上げる / 下げる（5% ずつ） |
| `M` | 消音の切り替え |
| `Shift` + `←` / `→` | 前 / 次のファイル |
