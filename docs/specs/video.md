# 動画

動画（mp4 / m4v / webm / mov / mkv）を開くと、同じフォルダの動画だけが自然順で並びます（画像・音楽は飛ばします。並び方は [files.md](files.md) を参照）。動画を表示している間は `←` `→`・ホイールが早送り・巻き戻し、右ボタンを押したまま / `Ctrl` を押しながらのホイールが音量になります。前後のファイルへは再生操作カードの ⏮ ⏭ ボタンとマウスのサイドボタンで移ります（キーでは移りません。画像のときの操作カードの代わりに再生操作カードを出します）。

> [!NOTE]
> sView は PC / OS に内蔵の WebView（Windows: WebView2 / macOS: WKWebView）で再生するだけの簡素な作りで、コーデックを同梱していません。
> そのため、**再生できるのはその PC / OS 自体が再生できる形式に限られます**。同じファイルでも、PC のハードウェアや OS のバージョンによって再生できたりできなかったりします（再生できないファイルはエラーを表示します）。

- 形式ごとの目安は次のとおりです

  | 形式 | Windows | macOS |
  | --- | --- | --- |
  | MP4 / M4V（H.264 + AAC） | 可 | 可 |
  | MP4（HEVC） | 対応ハードウェアと OS の HEVC 拡張機能があれば可 | 可 |
  | MOV | 中身によって可（保証なし） | 可 |
  | WebM（VP8 / VP9） | 可 | macOS のバージョンによる |
  | MKV | 中身によって可（字幕は SRT / ASS のみ） | 映像が H.264 / HEVC、音声が AAC / Opus のものだけ可（字幕は SRT / ASS のみ） |
  | AV1（MP4 / WebM） | 可 | AV1 のハードウェアデコーダを持つ Mac（M3 以降）と macOS 14 以降でのみ可 |

- macOS の WebView は MKV を再生できないため、macOS では MKV の中身（映像・音声）を再エンコードせずに MP4 の形へ詰め直しながら再生します（コーデックは同梱せず、デコードは OS が行います）
  - 対応するのは映像が H.264 / HEVC、音声が AAC / Opus のものだけです。HEVC は Mac のハードウェアと macOS のバージョンによっては再生できません
  - 映像が対応していない MKV（VP9・AV1 など）は、エラーを表示して再生しません
  - 既定の音声が対応していない（AC-3・DTS・FLAC など）ときは、対応している別の音声があればそれを、無ければ音声なしで再生し、そのことを知らせます。右クリックメニューの「音声」では、対応していない音声はグレーアウトしてコーデック名を添えます
  - 音声を切り替えると、今の位置から読み込み直します（一瞬止まります）
  - 再生位置の前後数十秒分だけを読み込み、それより前は手放すので、長い動画でもメモリは増え続けません
- MKV に入っているテキスト字幕（SRT / ASS）を表示できます。右クリックメニューの「字幕」に合わせると「オフ」と字幕の一覧が出るので、そこから選びます。開いたときは常にオフです（動画で既定とされている字幕があっても表示しません）。選んだ字幕は保存しません
  - 表示するのは文字だけです。ASS の文字の装飾・色・表示位置は反映せず、すべて画面の下端から 1 行分上に白い文字で出します（SRT の斜体・太字・下線は反映します）
  - PGS・VobSub などの画像の字幕は表示できません（一覧にも出ません）
- 音声が 2 つ以上入っている動画（副音声のある MKV など）では、右クリックメニューの「音声」に合わせて出る一覧から音声を選べます。開いたときは動画で既定とされている音声を再生します。選んだ音声は保存しません（ほかの動画を開くと、その動画の既定の音声に戻ります）。Windows ではこの切り替えに WebView2 の実験的機能を使っているため、WebView2 のバージョンによっては「音声」がグレーアウトすることや、選んでも音声が変わらないことがあります
- 右クリックメニューの「字幕」「音声」は動画を開いているときだけ出ます。選べる字幕が無い、または音声が 1 つだけのときは、その項目はグレーアウトして選べません
- AVI などそのほかの形式は対象外で、開けません

- マウスを動かすと、下部中央に再生操作のカードが出ます。上段がシークバー、下段は左に再生時間（現在 / 全体）、中央に 5 秒戻る・再生 / 一時停止・5 秒進む、右に消音と音量です。シークバーにカーソルを乗せるとその位置の時刻、音量つまみに乗せると今の音量が出ます。シークバーと音量つまみは、済んだ側（再生済み・今の音量まで）を白、残りを暗い色で塗り分けます（OS 標準の見た目は使わず、Windows と macOS で同じ見た目にしています）。ほかの表示と同じく、マウスを止めて 3 秒たつか、ウィンドウの外へ出るか、ほかのウィンドウに切り替えると隠れます
- 動画の上を押してすぐ離すと再生 / 一時停止、押したままマウスを動かすとウィンドウを移動します
- 動画は常にウィンドウに合わせて表示し、拡大縮小はしません。設定「メディアに合わせる」では動画の縦横比にウィンドウを合わせます
- 設定の「動画」タブで、開いたらすぐ再生するかと、動画が終わったら「次の動画へ進む」（既定）「同じ動画を繰り返す」「止める」のどれにするかを変えられます。「次の動画へ進む」は一覧の次の動画を続けて再生し、最後の動画のあとは止まります（以前の「動画を繰り返し再生する」がオフだった場合は「止める」になります）。音量は再生操作のつまみ・`↑` `↓` キー・右ボタンを押したまま / `Ctrl` を押しながらのホイールで変え、動画用として保存されます（音楽とは別）。消音は保存しません
- 圧縮フォルダ（zip / cbz）の中の動画は一覧に出しません
- 各拡張子は OS に関連付けられます（インストーラーと、設定ウィンドウの「動画」タブの「関連付け」）

## 動画表示中のキー操作

動画を表示している間だけ、次のキーが動画の操作になります。画像の前後移動に使う `PageUp` `PageDown` `Backspace` `Home` `End` は何もしません。

| キー | 動作 |
| --- | --- |
| `Space` / `K` / 動画をクリック | 再生 / 一時停止 |
| `←` / `→`、`J` / `L` | 5 秒戻る / 進む |
| `↑` / `↓` | 音量を上げる / 下げる（5% ずつ） |
| `M` | 消音の切り替え |

マウスでは、サイドボタンの「戻る / 進む」が前 / 次のファイル、ホイールが 3 秒戻る / 進む（下に回すと進む）、右ボタンを押したまま / `Ctrl` を押しながらのホイールが音量（上に回すと大きく）です。再生操作カードの中央は左から ⏮（前のファイル）・5 秒戻る・再生 / 一時停止・5 秒進む・⏭（次のファイル）の順に並びます。
