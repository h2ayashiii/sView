# 動画

動画（mp4 / m4v / webm / mov）を開くと、同じフォルダの動画だけが自然順で並びます（画像・音楽は飛ばします。並び方は [files.md](files.md) を参照）。動画を表示している間は `←` `→` とマウスのサイドボタンが早送り・巻き戻し、ホイールが音量になります。前後のファイルへは再生操作カードの ⏮ ⏭ ボタンでだけ移ります（キー・マウスでは移りません。画像のときのウィンドウ左右の `❮` `❯` ボタンも出しません）。

> [!NOTE]
> sView は PC / OS に内蔵の WebView（Windows: WebView2 / macOS: WKWebView）で再生するだけの簡素な作りで、コーデックを同梱していません。
> そのため、**再生できるのはその PC / OS 自体が再生できる形式に限られます**。同じファイルでも、PC のハードウェアや OS のバージョンによって再生できたりできなかったりします（再生できないファイルはエラーを表示します）。

- 形式ごとの目安は次のとおりです

  | 形式 | Windows | macOS |
  | --- | --- | --- |
  | MP4 / M4V（H.264 + AAC） | 可 | 可 |
  | MP4（HEVC） | 対応ハードウェアと OS の HEVC 拡張機能があれば可 | 可 |
  | MOV | 中身によって可（保証なし） | 可 |
  | WebM（VP8 / VP9） | 可 | macOS のバージョンによる |
  | AV1（MP4 / WebM） | 可 | AV1 のハードウェアデコーダを持つ Mac（M3 以降）と macOS 14 以降でのみ可 |

- MKV・AVI などは対象外で、開けません（macOS の WebView はそもそも MKV に対応していません）

- マウスを動かすと、下部中央に再生操作のカードが出ます。上段がシークバー、下段は左に再生時間（現在 / 全体）、中央に 5 秒戻る・再生 / 一時停止・5 秒進む、右に消音と音量です。シークバーにカーソルを乗せるとその位置の時刻、音量つまみに乗せると今の音量が出ます。シークバーと音量つまみは、済んだ側（再生済み・今の音量まで）を白、残りを暗い色で塗り分けます（OS 標準の見た目は使わず、Windows と macOS で同じ見た目にしています）。ほかの表示と同じく、マウスを止めて 3 秒たつか、ウィンドウの外へ出るか、ほかのウィンドウに切り替えると隠れます
- 動画の上を押してすぐ離すと再生 / 一時停止、押したままマウスを動かすとウィンドウを移動します
- 動画は常にウィンドウに合わせて表示し、拡大縮小はしません。設定「メディアに合わせる」では動画の縦横比にウィンドウを合わせます
- 設定の「動画」タブで、開いたらすぐ再生するかと、動画が終わったら「次の動画へ進む」「同じ動画を繰り返す」（既定）「止める」のどれにするかを変えられます。「次の動画へ進む」は一覧の次の動画を続けて再生し、最後の動画のあとは設定「端で最初 / 最後へ折り返す」がオンのときだけ先頭に戻ります（以前の「動画を繰り返し再生する」がオフだった場合は「止める」になります）。音量は再生操作のつまみ・`↑` `↓` キー・ホイールで変え、動画用として保存されます（音楽とは別）。消音は保存しません
- 圧縮フォルダ（zip / cbz）の中の動画は一覧に出しません
- 各拡張子は OS に関連付けられます（インストーラーと、設定ウィンドウの「動画」タブの「関連付け」）

## 動画表示中のキー操作

動画を表示している間だけ、次のキーが動画の操作になります。画像の前後移動に使う `PageUp` `PageDown` `Backspace` `Home` `End` は何もしません。

| キー | 動作 |
| --- | --- |
| `Space` / `K` / 動画をクリック | 再生 / 一時停止 |
| `←` / `→`、`J` / `L` | 5 秒戻る / 進む |
| `↑` / `↓` | 音量を上げる / 下げる（5% ずつ） |
| `M` | 消音の切り替え |

マウスでは、サイドボタンの「戻る / 進む」が 5 秒戻る / 進む、ホイールが音量（上に回すと大きく）です。再生操作カードの中央は左から ⏮（前のファイル）・5 秒戻る・再生 / 一時停止・5 秒進む・⏭（次のファイル）の順に並びます。
