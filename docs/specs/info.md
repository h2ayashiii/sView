# ファイルの情報

表示・再生中のファイルの情報（画像の解像度や Exif、動画・音楽のコーデックやタグなど）を、別のウィンドウに一覧で出します。

## 開き方・閉じ方

- 右クリックメニューの「ファイルの情報」か、`I` キーで開きます。何も表示していないときは、メニューの項目はグレーアウトします（`I` で開くと「ファイルを表示していません」と出ます）
- もう一度 `I` を押すと閉じます。情報ウィンドウの上でも `I` か `Esc`、または閉じるボタンで閉じます
- 開いたまま前後のファイルへ移ると、その都度そのファイルの情報に切り替わります。macOS で複数のビューアを開いているときは、操作している（前面の）ビューアのファイルの情報を出します
- 本モードの見開きでは、前のページ（一覧で先の方）の情報を出します
- 圧縮フォルダ（zip / cbz）の中の画像は、その画像そのものの情報を出します（書庫の場所・書庫の中での場所・圧縮前と圧縮後の大きさを含む）
- 開くたびに読み直します（ファイルを書き換えたあとに開き直せば、新しい内容になります）
- 値は文字を選んでコピーできます。右上の「コピー」で、すべての情報をテキストとしてコピーできます
- 配色は設定ウィンドウと同じく「背景色」から作ります。背景は「背景の不透明度」によらず、常に不透明（100%）で表示します

## 出す情報

読めない・入っていない項目は出しません。情報はファイルのヘッダ（先頭や目次の部分）だけを読んで集め、映像・音声のデコードはしません。

### すべてのファイル（ファイル）

名前・場所・サイズ・更新日時・作成日時。日時は PC の地域の時刻で出します。圧縮フォルダの中の画像の更新日時は、書庫に記録されたまま（タイムゾーンを持たない）で出します。

### 画像

| 欄 | 項目 |
| --- | --- |
| 画像 | 形式（中身から判定。JPEG / PNG / GIF / WebP / BMP / ICO / TIFF / AVIF / HEIF / SVG）、解像度（とメガピクセル）、PNG の色の深さと種類 |
| 撮影情報（Exif） | メーカー・機種・レンズ・撮影日時・露出時間・F 値・ISO 感度・焦点距離（35mm 換算）・露出補正・露出プログラム・フラッシュ・ホワイトバランス・向き・位置（緯度・経度）・高度・ソフトウェア・説明・作者・著作権 |

- SVG は解像度を出しません（決まった大きさを持たないため）
- Exif は JPEG / TIFF / PNG / WebP / AVIF / HEIF から読みます。撮影情報が 1 つも無ければ「撮影情報」の欄は出しません
- 位置（GPS）が入っている画像では、その緯度・経度をそのまま出します

### 動画

| 欄 | 項目 |
| --- | --- |
| 全般 | コンテナ（MP4 / M4V / QuickTime (MOV) / Matroska / WebM）、長さ、全体のビットレート、タイトル、エンコーダ、作成日時、チャプター（MKV は数、MP4 / MOV は有無） |
| 映像 | コーデック（H.264 / H.265 / AV1 / VP9 / VP8 / ProRes など）、プロファイルとレベル、解像度、表示サイズ（画素の縦横比が正方形でないとき）、縦横比、フレームレート、ビットレート（MP4）、ビット深度、色域、HDR（HDR10 / HLG / Dolby Vision） |
| 音声 | コーデック（AAC LC / HE-AAC / Opus / AC-3 / E-AC-3 / FLAC など）、チャンネル、サンプリング周波数、ビット深度（非圧縮・可逆圧縮のとき）、ビットレート（MP4）、言語、名前、既定 / 強制（MKV で 2 つ以上あるとき） |
| 字幕 | 形式（SRT / ASS / PGS / MPEG-4 Timed Text など）、言語、名前、既定 / 強制（MKV で 2 つ以上あるとき） |

- 音声・字幕が 2 つ以上あれば「音声 1」「音声 2」のように番号を付けて並べます
- MP4 のフレームレートとトラックごとのビットレートは、サンプルの数と大きさから求めた平均です（可変フレームレートの動画では平均の値になります）。fragmented MP4 では出しません
- MKV のフレームレートは、ファイルに書かれた 1 フレームの長さから求めます（書かれていなければ出しません）
- 再生できない形式（OS が対応していないコーデック）の動画でも、ヘッダが読めれば情報は出します

### 音楽

| 欄 | 項目 |
| --- | --- |
| 音声 | コーデック（MP3 / AAC LC / HE-AAC / ALAC / FLAC / Opus / Vorbis / PCM (WAV) など）、長さ、ビットレート、サンプリング周波数、ビット深度、チャンネル |
| タグ | 曲名・アーティスト・アルバム・アルバムアーティスト・作曲者・ジャンル・日付・トラック・ディスク・コメント・エンコーダ・埋め込みアートワーク（形式と大きさ） |

- タグが 1 つも無ければ「タグ」の欄は出しません

## 読めなかったとき

- ファイルそのものを読めないとき（消された・権限が無いなど）は、その理由を出します
- 中身が壊れている・形式が判定できないときは、「ファイル」の欄だけを出して、読めなかった理由を添えます
