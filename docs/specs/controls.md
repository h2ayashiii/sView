# 操作

## 画像を開く

画像ファイル・動画ファイル・音楽ファイル・フォルダ・圧縮フォルダ（zip / cbz）のいずれも開けます。

- ファイル / フォルダ / zip・cbz をウィンドウにドラッグ＆ドロップ
- 起動直後の画面をクリック、または `O` キーでファイルダイアログ、`D` キーでフォルダダイアログを開く
- コマンドライン引数にパスを渡して起動（`sView path/to/image.png`、`sView path/to/folder`、`sView path/to/book.cbz`）
- OS の「このアプリで開く」（ファイル関連付け。画像・動画・音楽を関連付けます。設定の「関連付け」で拡張子ごとに選べます）

## キーボード

| キー | 動作 |
| --- | --- |
| `→` `PageDown` `Space` | 次の画像 |
| `←` `PageUp` `Backspace` | 前の画像 |
| `Home` / `End` | 最初 / 最後の画像 |
| `+` / `-` | ズームイン / アウト |
| `0` | ウィンドウにフィット |
| `1` | 等倍（100%）表示 |
| `O` | ファイル（画像 / 圧縮フォルダ）を開く |
| `D` | フォルダを開く |
| `R` | 再スキャン |
| `F` | フルスクリーン切り替え |
| `Del`（macOS は `⌘ Delete` でも可） | 表示中の画像をゴミ箱へ移動 |
| `⌘ ,`（macOS）/ `Ctrl` + `,`（Windows） | 設定を開く |
| `Esc` | メニューを閉じる / 終了 |

`↑` `↓` は画像の表示中は何もしません（今後の機能のために空けてあります）。

動画・音楽を表示している間のキー操作は [動画](video.md#動画表示中のキー操作) を参照してください（音楽も同じです）。

前後移動は既定では端で折り返しません。最後の画像で「次へ」、最初の画像で「前へ」を押すと、その旨を短く表示してその画像に留まります（設定で折り返すようにもできます）。

## マウス

| 操作 | 動作 |
| --- | --- |
| 「進む」ボタン（サイドボタン） | 次の画像（動画・音楽では 5 秒進む） |
| 「戻る」ボタン（サイドボタン） | 前の画像（動画・音楽では 5 秒戻る） |
| ホイール | カーソル位置を中心にズーム（動画・音楽では音量） |
| 右クリック | コンテキストメニューを開く |
| ドラッグ（フィット表示時） | ウィンドウの移動 |
| タイトルバー（上部）のダブルクリック | 最大化 / 元のサイズに戻す |
| ドラッグ（ズーム中） | 画像のパン |
| 左右の `❮` `❯` ボタン（マウスを動かすと表示） | 前 / 次の画像 |

## 右クリックメニュー

アプリのどこでも右クリックするとコンテキストメニューが開きます。

| 項目 | 動作 |
| --- | --- |
| エクスプローラー / Finder で表示 | 表示中のファイルを OS のファイルマネージャーで選択状態にして開きます（書庫を開いている場合は書庫ファイル自体） |
| ゴミ箱へ移動… | 表示中の画像を OS のゴミ箱へ移動します（圧縮フォルダの中の画像は対象外なので選べません） |
| ファイルを開く… / フォルダを開く… | ファイル選択ダイアログを開きます |
| 再読み込み | 現在のフォルダ・書庫を読み直します |
| 再生 / 一時停止、消音 | 動画・音楽を表示しているときだけ出ます |
| ウィンドウに合わせる / 等倍 (100%) / 全画面表示 | 表示倍率の切り替え |
| 設定… | 設定ウィンドウを開きます |
| 終了 | アプリを終了します |
