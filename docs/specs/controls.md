# 操作

## 開く

画像ファイル・動画ファイル・音楽ファイル・フォルダ・圧縮フォルダ（zip / cbz）のいずれも開けます。開いたあとに並ぶファイルの範囲は [files.md](files.md) を参照してください。

- ファイル / フォルダ / zip・cbz をウィンドウにドラッグ＆ドロップ
- 起動直後の画面をクリック、または `O` キーでファイルダイアログ、`D` キーでフォルダダイアログを開く
- コマンドライン引数にパスを渡して起動（`sView path/to/image.png`、`sView path/to/folder`、`sView path/to/book.cbz`）
- OS の「このアプリで開く」（ファイル関連付け。画像・動画・音楽を関連付けます。設定の各タブの「関連付け」で拡張子ごとに選べます。圧縮フォルダは関連付けません）

## 画面の表示

ウィンドウには枠もタイトルバーもありません。マウスを動かすと次のものが重ねて表示され、3 秒動かさないか、ウィンドウの外へ出るか、ほかのウィンドウに切り替えると消えます。

- ウィンドウ操作ボタン（macOS は左上に「閉じる / 最小化 / 最大化」、Windows は右上に「最小化 / 最大化 / 閉じる」）。最小化・最大化の挙動は OS 標準どおりです
- 左右の `❮` `❯` ボタン（画像のときだけ）
- 左下のファイル名と右下の枚数（設定で消せます）
- 動画・音楽のときは下部中央の再生操作カード（[video.md](video.md)）

大きさはウィンドウの端や角をドラッグして変えます（[window-size.md](window-size.md)）。

## キーボード

| キー | 動作 |
| --- | --- |
| `→` `PageDown` `Space` | 次の画像 |
| `←` `PageUp` `Backspace` | 前の画像 |
| `Home` / `End` | 最初 / 最後の画像 |
| `B` | 本モード（2 ページ表示）の切り替え |
| `+` / `-` | ズームイン / アウト |
| `0` | ウィンドウにフィット |
| `1` | 等倍（100%）表示 |
| `O` | ファイル（画像・動画・音楽・圧縮フォルダ）を開く |
| `D` | フォルダを開く |
| `R` | 再スキャン |
| `F` | フルスクリーン切り替え |
| `Del`（macOS は `⌘ Delete` / `fn Delete`） | 表示中のファイルをゴミ箱へ移動 |
| `⌘ ,`（macOS）/ `Ctrl` + `,`（Windows） | 設定を開く |
| `Esc` | メニューを閉じる / ウィンドウを閉じる（終了） |

`↑` `↓` は本モードのときだけ 1 ページずつずらすのに使い、1 ページ表示の画像では何もしません（今後の機能のために空けてあります）。本モードのページ送りは [本モード](book.md#ページ送り) を参照してください。

macOS の `Delete` キー（`fn` なし）は `Backspace` と同じ扱いで、前の画像へ移ります。

動画・音楽を表示している間は、`←` `→` `↑` `↓` `Space` などが再生の操作になります。[動画](video.md#動画表示中のキー操作) を参照してください（音楽も同じです）。

前後移動は既定では端で折り返しません。最後の画像で「次へ」、最初の画像で「前へ」を押すと、その旨を短く表示してその画像に留まります（設定で折り返すようにもできます）。

## マウス

| 操作 | 動作 |
| --- | --- |
| 「進む」ボタン（サイドボタン） | 次の画像（動画・音楽では 5 秒進む） |
| 「戻る」ボタン（サイドボタン） | 前の画像（動画・音楽では 5 秒戻る） |
| ホイール | カーソル位置を中心にズーム（動画・音楽では音量） |
| 右クリック | コンテキストメニューを開く |
| ドラッグ（フィット表示時） | ウィンドウの移動 |
| クリック（動画・音楽） | 再生 / 一時停止（押したまま動かすとウィンドウの移動） |
| タイトルバー（上部）のダブルクリック | 最大化 / 元のサイズに戻す |
| ドラッグ（ズーム中） | 画像のパン |
| 左右の `❮` `❯` ボタン（画像のとき、マウスを動かすと表示） | 前 / 次の画像 |
| 再生操作カードの ⏮ ⏭ ボタン（動画・音楽） | 前 / 次のファイル |

## 右クリックメニュー

アプリのどこでも右クリックするとコンテキストメニューが開きます。

| 項目 | 動作 |
| --- | --- |
| エクスプローラー / Finder で表示 | 表示中のファイルを OS のファイルマネージャーで選択状態にして開きます（書庫を開いている場合は書庫ファイル自体） |
| ゴミ箱へ移動… | 表示中のファイルを OS のゴミ箱へ移動します（圧縮フォルダの中の画像と本モードでは選べません。[files.md](files.md#ファイルの削除)） |
| 本モード（2 ページ表示） | 画像を 2 ページずつ並べる表示の切り替え（画像の一覧のときだけ。[book.md](book.md)） |
| 左開き / 右開き | 本モードで前のページを左に置くか右に置くか（日本の漫画などは右開き） |
| ファイルを開く… / フォルダを開く… | ファイル / フォルダの選択ダイアログを開きます |
| 再読み込み | 現在のフォルダ・書庫を読み直します |
| 全画面表示 | 全画面表示の切り替え |
| 設定… | 設定ウィンドウを開きます |
| 終了 | ウィンドウを閉じてアプリを終了します（macOS で複数のウィンドウを開いているときは、そのウィンドウだけを閉じます） |
