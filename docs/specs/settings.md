# 設定・ログ・キャッシュ

## 設定

右クリックメニューの「設定…」または `⌘ ,`（Windows は `Ctrl` + `,`）で、本体とは別の設定ウィンドウが開きます。項目は「全般」「画像」「動画」「音楽」の 4 つのタブに分けてあり、選んだタブの項目だけを表示します（収まらない分はスクロールします）。開くたびに「全般」から始まるのではなく、前回閉じたときのタブのままです。変更は即座に本体へ反映され、OS の設定フォルダの中の `sview`（Windows: `%APPDATA%\sview`、macOS: `~/Library/Application Support/sview`）にある `settings.json` に保存されます。このフォルダ名はアプリの識別子（macOS の bundle ID として使う逆ドメイン名 `io.github.h2ayashiii.sview`）とは切り離してあり、どの OS でも `sview` です。

| タブ | 分類 | 項目 |
| --- | --- | --- |
| 全般 | 外観 | 背景色 / 背景の不透明度 / ファイル名（左下）と枚数（右下）の表示 |
| 全般 | ウィンドウ | ウィンドウのサイズ（自由に変更・メディアに合わせる）/ ファイルの種類ごとにウィンドウを保持する / 常に最前面に表示 |
| 全般 | 操作 | ホイールの感度 / 端での折り返し / マウスのサイドボタン |
| 全般 | ファイル | 削除の前に確認する / フォルダの変更を自動で取り込む |
| 全般 | ログ | ログフォルダを開く |
| 画像 | 表示 | 画像を開いたときの表示倍率（フィット・等倍）/ 拡大時の補間 / 前後の画像の先読み |
| 画像 | 関連付け | sView で開く画像の種類（拡張子） |
| 動画 | 動画の再生 | 動画を開いたらすぐ再生する / 動画が終わったら（次の動画へ進む・同じ動画を繰り返す・止める） |
| 動画 | 関連付け | sView で開く動画の種類（拡張子） |
| 音楽 | 音楽の再生 | 音楽を開いたらすぐ再生する / 曲が終わったら（次の曲へ進む・同じ曲を繰り返す・止める） |
| 音楽 | 関連付け | sView で開く音楽の種類（拡張子） |

「ファイルの種類ごとにウィンドウを保持する」（既定はオフ）をオンにすると、ウィンドウの大きさと位置を画像・動画・音楽で別々に覚えます。詳しくは [window-size.md](window-size.md#ファイルの種類ごとにウィンドウを保持する)。

関連付けは種類ごとのタブにあり、「関連付ける」はそのタブの拡張子だけを変更します（他の種類の関連付けはそのまま残ります）。

ウィンドウの角は常に丸く（最大化中は四角）、画像のときのウィンドウ左右の移動ボタンは常に表示します。動画・音楽の音量は設定ウィンドウには無く、再生操作の音量つまみ・`↑` `↓` キー・ホイールで変えた値を動画と音楽で別々に保存します。消音は保存せず、起動したときは常に音が出る状態です。

各項目には簡単な説明を添えてあります。「既定に戻す」ですべての項目を初期値に戻せます（動画・音楽の音量は戻しません）。設定ウィンドウの配色（背景の色と透け具合、文字色、分類の見出しバー）は「背景色」「背景の不透明度」から作るため、本体ウィンドウと同じ見た目になります。

設定ウィンドウは閉じても破棄せず隠すだけで、次に開くときは同じウィンドウを表示します。本体ウィンドウを閉じるとアプリごと終了します。

設定ウィンドウの左下には、実行中のアプリのバージョンを表示します（`tauri.conf.json` の `version`。タグから作ったリリースではタグの値と一致します）。

## ログ

動作の記録は `settings.json` と同じフォルダの中の `logs`（Windows: `%APPDATA%\sview\logs`、macOS: `~/Library/Application Support/sview/logs`）に `sview.log` として出ます。設定ウィンドウの「ログフォルダを開く」からも辿れます。

- 2MB ごとにファイルを切り替え、直近 3 本だけ残すので放置しても膨らみません
- 異常終了（パニック）したときは、その内容とバックトレースもログに残ります
- 通信は一切しません。ログは手元にしか残らないので、**不具合を報告するときは内容を確認してから添えてください**

## キャッシュ

sView 自身はキャッシュをディスクに書きませんが、画面の描画に使う OS の WebView が localStorage やキャッシュを置きます。設定やログとは別の場所です。

| OS | 置き場所 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\sview` |
| macOS | `~/Library/Caches/io.github.h2ayashiii.sview`、`~/Library/WebKit/io.github.h2ayashiii.sview` |

消してしまっても問題ありません（次回起動時に作り直されます）。macOS だけフォルダ名がアプリの識別子（bundle ID）になっているのは、WKWebView には置き場所を指定する仕組みが無く、OS が bundle ID から決めているためです。
