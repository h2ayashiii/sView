# 音楽

音楽ファイル（mp3 / m4a / aac / flac / wav / ogg / opus）を開くと、同じフォルダの音楽ファイルだけが自然順で並びます（画像・動画は飛ばします。並び方は [files.md](files.md) を参照）。音楽を表示している間は、ウィンドウにアートワークを出し、その下の帯に曲名・アーティスト・アルバム名を出します。

> [!NOTE]
> 動画と同じく、再生は PC / OS に内蔵の WebView（Windows: WebView2 / macOS: WKWebView）に任せていて、コーデックは同梱していません。
> **再生できるのはその PC / OS 自体が再生できる形式に限られます**（再生できないファイルはエラーを表示します）。

- 形式ごとの目安は次のとおりです

  | 形式 | Windows | macOS |
  | --- | --- | --- |
  | MP3 | 可 | 可 |
  | M4A / AAC（AAC） | 可 | 可 |
  | M4A（ALAC） | 不明 | 可 |
  | FLAC | 可 | 可 |
  | WAV（PCM） | 可 | 可 |
  | OGG（Vorbis）/ OPUS | 可 | macOS のバージョンによる（保証なし） |

- WMA・APE などは対象外で、開けません
- 圧縮フォルダ（zip / cbz）の中の音楽は一覧に出しません
- 各拡張子は OS に関連付けられます（インストーラーと設定ウィンドウの「関連付け」）

## 表示

- アートワークは次の順に探します
  1. ファイルのタグに埋め込まれた画像（表紙として登録されたものを優先）
  2. 同じフォルダの `cover` / `folder` / `front` / `album` / `albumart` という名前の画像（`cover.jpg`・`Folder.png` など。大文字小文字は区別しません）
  3. どちらも無ければ既定の絵（音符）
- 曲名・アーティスト・アルバム名はタグから読みます。曲名が無いときはファイル名を出します
- アートワークとウィンドウの縁のあいだには、左右と上に余白（28px）を空けます（下は曲名の帯と再生操作のカードがあります）
- アートワークの角は、ウィンドウの角と同じだけ丸めます（既定の絵も同じ）
- 設定「ウィンドウのサイズ」が「画像に合わせる」のときは、ウィンドウを「余白＋アートワーク＋曲名の帯」の形に合わせます。余白と帯の高さはウィンドウの大きさによらず一定で、縦横比はウィンドウからこの分を除いた部分をアートワークに合わせます。そのため、曲を切り替えても手で大きさを変えても、余白は左右・上とも同じ幅のままです。アートワークは拡大縮小しません
- マウスを動かすと、動画と同じ再生操作のカード（シークバー・再生時間・5 秒戻る / 再生 / 5 秒進む・消音・音量）が曲名の帯の上に出ます。隠れている間は、帯に細い線で再生位置だけを出します
- アートワークの上を押してすぐ離すと再生 / 一時停止、押したままマウスを動かすとウィンドウを移動します
- キー操作は動画と同じです（[動画表示中のキー操作](video.md#動画表示中のキー操作)）

## 音量

音楽は動画より音が大きいことが多いため、音量つまみの 100% のとき、実際には素材の音量の半分（-6 dB）で鳴らします。つまみの表示・`↑` `↓` キー・設定「音量」の値は動画と共通の 0〜100% のままです（音量を上げても、動画から音楽へ切り替えたときに急に大きくなりません）。曲ごとの音量の差までは揃えません。

## 設定

設定の「動画・音楽」で次を変えられます。消音と音量は動画と共通です。

- 音楽を開いたらすぐ再生するか
- 曲が終わったら: 「次の曲へ進む」（既定）/「同じ曲を繰り返す」/「止める」
  - 「次の曲へ進む」は一覧の次の音楽ファイルを続けて再生します。一覧には音楽しか並ばないので、アルバムのフォルダに `cover.jpg` があっても止まりません
  - 最後の曲のあとは、設定「端で最初 / 最後へ折り返す」がオンのときだけ先頭の曲に戻ります。オフなら止まります
